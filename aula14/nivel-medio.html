Nível Médio — Cards com Flexbox

Card 1 — HTML

HTML é a linguagem de marcação usada para estruturar o conteúdo de páginas web, definindo títulos, parágrafos, listas e muito mais.

Card 2 — CSS

CSS é a linguagem de estilo responsável pela aparência visual das páginas. Com ela, controlamos cores, fontes, espaçamentos e layouts.

Card 3 — Flexbox

Flexbox é um modelo de layout do CSS que facilita alinhar e distribuir elementos dentro de um container de forma flexível e responsiva.
